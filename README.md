## Run locally

```bash
# open directly
open index.html          # macOS   (use "start" on Windows)

# or serve it
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy (GitHub Pages)

This repo is named `saipanguluri-lab.github.io`, so GitHub Pages serves it automatically at
the root URL. If it isn't live, go to **Settings → Pages → Deploy from branch → main / root**.
